## 五种评测方式

1. **bazi_kg** - 八字 + 结构化知识图谱
2. **bazi_fewshot** - 八字 + 知识图谱 + 8 条训练集 few-shot
3. **bazi_full** - 八字 + 知识图谱 + 命例 RAG + few-shot (推荐主流程)
4. **fusion** - 八字 + 六爻时间卦 + 动态合并
5. **liuyao_only** - 仅六爻时间卦 MCQ

## 运行全量评测 (200 题 x 多方法)

需配置 `code/backend/.env` 中 `BAZI_DEEPSEEK_API_KEY`, 并启动 RAG:

```powershell
cd d:\ZY\code\rag
.\start-rag.bat
```

```powershell
cd d:\ZY\code\backend
python scripts/contest_methods_benchmark.py --split all --methods all --skip-existing
```

完成后自动刷新 `report/命理师大赛-算命方式对比.md`. 也可手动:

```powershell
python scripts/generate_contest_comparison_md.py
python scripts/analyze_contest_errors.py --method bazi_kg
```

原始 JSON: `code/backend/data/reports/contest8_{split}_{method}.json`
