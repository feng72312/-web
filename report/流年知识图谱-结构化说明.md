# 流年知识图谱 - 结构化说明

## 背景

大赛错题分析显示: **流年/应期类**题目依赖「大运 + 流年 + 用神」联动, 原先知识图谱仅有调候(`tiaohou`)等本命节点, 流年规则散落在 `数据库/01八字命理/命理探源--袁树珊.txt` 等原文中, 未结构化注入评测。

## 已结构化内容

来源: **命理探源** 论流年、论岁运宫限、战冲和好、推流年法等章节 (摘录整理, 非全文).

| 节点 category | 内容要点 |
|---------------|----------|
| `core` | 太岁与大运君臣、流年主一年祸福 |
| `taisui_relation` | 岁伤日主 / 日犯岁君、五行有救 |
| `zhen_taisui` | 真太岁、日柱与流年冲克 |
| `suiyun_binglin` | 岁运并临、羊刃七煞 vs 财官印 |
| `dayun_synergy` | 大运地支、太岁天干、喜忌权变 |
| `zhan_chong_he` | 运伐岁、岁伐运、冲、和 |
| `yongshen_timing` | 用神得助/受制与应期 |
| `xiaoyun_note` | 小运、小限、命宫 |
| `push_method` | 以流年干支论十神、合大运四柱 |

共 **15** 个流年节点 + **6** 个大运节点, 编译后 `nodes.jsonl` 合计 **121** (含调候 100).

## 技术实现

1. **种子脚本**: `code/knowledge/scripts/seed_liunian_nodes.py`
2. **编译图谱**: `py -3.10 scripts/compile_graph.py` (在 `code/knowledge` 目录)
3. **检索**: `topic=liunian`, `lookupKey.category` 按题干关键词选配 (见 `keys_liunian.py`)
4. **默认主题**: `DEFAULT_TOPICS` 已加入 `liunian`
5. **大赛评测**: `resolve_for_chart(chart, question=...)` 注入流年规则
6. **提示词增强**: `liunian_context.py` + `target_year_block.py` 在应期题追加:
   - 结构化 **流年时间轴** (从排盘 `dayun[].liunian[]` 提取题干年份)
   - **目标年结构化断语块** (大运/流年十神、岁运关系、与四柱冲合、题型十神线索)
   - 知识图谱 **大运+流年判断要点**

## 与 RAG 的分工

| 层 | 作用 |
|----|------|
| **知识图谱 liunian** | 稳定、可检索的流年判断 **规则** (君臣、战冲、并临) |
| **命例 RAG** | 同类命盘 **断语范例** |
| **排盘 dayun/liunian** | 命主具体 **干支与十神时间轴** |

三者同时进入大赛 MCQ 提示时, 应期题推理链更完整.
