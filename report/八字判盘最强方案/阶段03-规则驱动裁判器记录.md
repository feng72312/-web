## 核心实现

### 各裁判器行为

| 裁判器 | 输入 key | 图谱命中 | 降级 |
|--------|----------|----------|------|
| GejuJudge | monthShishen | classic_direct + ruleIds | 月令十神启发式 |
| QiShiJudge | dominant/weakest | classic_direct | 五行偏枯启发式 |
| ShiShenJudge | shishen+dayGan | classic_direct | 四柱十神拼接 |
| SuiYunJudge | dayun ganzhi | classic_direct | 首步大运描述 |
| TiaohouJudge | dayGan+monthZhi | 既有逻辑 | 不变 |

### 样例命盘(甲日寅月食神)

- geju ruleIds: `['geju:month:食神']`
- conclusionKind: `classic_direct`(图谱命中时)
- evidence_request 仍走 classicWhitelist + judgeOnly

### 失败降级策略

- knowledge store disabled -> 纯启发式, conclusionKind=rule_derived
- lookup 无行 -> 保留启发式 summary 与 synthetic ruleId
- ValueError(缺字段) -> 跳过图谱 lookup
