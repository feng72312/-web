# 阶段18-目标年大运定位与从格根气精细化记录

## 阶段目标

按题目目标年定位 active dayun, 让 SuiYunJudge / build_suiyun_key 使用当前大运而非首步大运; 从格(congcai/congsha) 仅在身弱且无地支通根时触发喵

## 本阶段变更

### luck_chart 模块 (新建)

- `resolve_target_year`: 从 chart / meta / benchmarkMeta / judgementContext 解析目标年
- `find_dayun_for_year`: 按 startYear-endYear 或流年反查大运
- `resolve_active_dayun`: 优先目标年所在大运, 否则首步
- `enrich_chart_for_judgement`: 写入 targetYear + activeDayun, 支持 question 推断

### keys / judges / chain

- `build_suiyun_key`: 改用 active dayun 干支
- `SuiYunJudge`: 摘要展示目标年 + 当前大运; evidence_request 同步 active 干支
- `BaziJudgementChain.run`: 新增 question / benchmark_meta 参数, 入口统一 enrich

### contest / baseline 接入

- `contest8_eval.predict_one`: enrich + 传入 question/meta
- `val_judgement_baseline_local.py`: 传入 item.question 与 enrich_question meta
- `target_year_block.py`: 复用 luck_chart.find_dayun_for_year

### 从格根气 (geju_special)

- `_day_master_root_score`: 天干通根 + 藏干通根; 日干本身不计入根气
- `congcai` / `congsha`: 需 strength==偏弱 且 root_score < 1.0 且财/杀星>=2

### 测试

- 新建 `tests/test_luck_chart.py` (5项)
- 更新 `tests/test_geju_special_patterns.py` (有根抑制从格)
