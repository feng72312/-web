# 阶段19-题目主题流年事件规则挂载记录

## 阶段目标

SuiYunJudge 按题目主题动态挂载 liunian:event_* 规则, 与 prompt 侧 select_liunian_categories 对齐; 前端/证据链拆分「流年事件」分组喵

## 本阶段变更

### keys_liunian

- 新增 `resolve_event_liunian_categories(question)`
- `THEME_EVENT_CATEGORIES` 映射官非/健康/婚姻/家庭/子女/流年事件
- `职业财运` 按题干关键词拆分为 event_career / event_wealth (修复原先只挂 wealth 的问题)

### SuiYunJudge

- `_question_from_chart` 读取 judgementQuestion
- `_collect_suiyun_rules` 改用 `select_liunian_categories(question)` 替代固定三类
- 挂载 event_* 时摘要追加「题目主题X: ...」
- evidence_request query 附带主题与 event category

### enrich / meta

- `enrich_chart_for_judgement` 写入 `judgementQuestion`
- `enrich_question` 新增 `questionTheme`

### 证据链与前端

- `evidence.py`: liunian:event_* 单独分组「流年事件」
- `BaziJudgementPanel`: ruleIds 与证据链均增加「流年事件」区

### 测试

- 新建 `tests/test_suiyun_event_theme.py`
