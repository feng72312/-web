# 阶段13-杂格条件触发与证据链分组记录

## 阶段目标

将杂格/外格/从格 ruleIds 从粗粒度五行偏旺触发, 升级为按日主强弱、十神分布、干支合冲等命局结构条件触发; 并让证据链按格局分组输出原文引用喵

## 本阶段变更

### 杂格条件检测模块

- 新建 `code/backend/app/core/knowledge/geju_special.py`
- `detect_geju_special_patterns(chart)` 按命局结构返回待挂载 pattern 列表
- 边界规则始终挂载: `zagai`, `waige`, `jishen_po`, `xionshen_cheng`
- 条件触发:
  - `zhuanwang`: 日主五行占比 >= 45%
  - `quzhi`: 偏旺五行占比 >= 42% 且非专旺
  - `congcai` / `congsha`: 日主偏弱且财/官杀十神 >= 2
  - `huaji`: 天干五合
  - `daochong`: 地支六冲
  - `chaoyang`: 丙丁日主冬月
  - `helu`: 日支带禄
  - `jinglan`: 申子辰水局含子
  - `xinghe`: 寅巳申或丑戌未刑
  - `yaohe`: 年干与时干遥合

### 判盘裁判

- `GejuJudge` 改为调用 `detect_geju_special_patterns`, 不再对所有题统一挂 `quzhi/zhuanwang`

### 知识库与证据链

- `KnowledgeStore.get_by_id()` 支持按 node id 取规则原文
- `build_evidence_chain` 对 geju 裁判按 月令格局/成败救应/杂格外格 分组输出多条证据链

### 测试

- 新建 `tests/test_geju_special_patterns.py` 覆盖化气、从财、倒冲等检测与 GejuJudge 挂载
