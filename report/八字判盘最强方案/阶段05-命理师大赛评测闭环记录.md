## 核心实现

### benchmark item 扩展字段(运行时 enrich)

| 字段 | 说明 |
|------|------|
| targetYear | 从题干解析 20xx 年份 |
| expectedReasoningTags | geju/tiaohou/dayun/liunian/shishen/... |
| mustCheckRules | geju:month, tiaohou, suiyun, shishen, qishi |
| forbiddenEvidenceTypes | case_reference, low_trust |
| errorLabels | ERROR_LABELS 全表 |

### 评测记录

- predict_one 已接入 BaziJudgementChain + infer_error_labels
- judgement dict 新增 benchmarkMeta 与 coverage(missingTags, caseOverreach)
- prompts_contest 注入五类裁判预结论, 禁止命例越权

### val split 回归命令

```bash
# 需先跑 eval 产出 JSON
python -m app.benchmark.contest8_eval --split val --output /tmp/val_eval.json
python -m app.benchmark.contest8_regression_report --split val --results /tmp/val_eval.json --output report/八字判盘最强方案/val_regression.json
```
