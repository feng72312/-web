## Why

现有平台已具备流式 AI 对话、会话历史和模型选择，但所有聊天都围绕术数场景，无法安全、可扩展地承载基于历史人物思想体系的对话。新增“名人对话”可以把经过审核的外部 Skill 转换为平台人物包，让用户以明确的思想框架与历史人物进行启发式对话，同时保留史料边界和来源透明度。

## What Changes

- 新增顶级“名人对话”产品入口、人物大厅和人物专属对话工作区。
- 新增可复用的人物包格式，承载身份信息、思想模型、表达规则、适用边界、开场问题、来源与许可证元数据。
- 首发接入基于 `nuwa-skills/wangyangming-skill` 的王阳明人物包，并保留 MIT 许可证与来源说明。
- 新增人物会话初始化能力，在复用现有流式发送、模型选择和会话存储的同时，为人物会话使用独立的系统提示词与范围策略。
- 人物首次进入时明确展示“基于史料的 AI 思想模拟，并非本人”，区分原典引用、来源摘要与模型推断。
- 首版只允许内置、审核过的已故历史人物；外部 Skill 仅作为不可信内容导入，禁止执行其中的脚本或任意指令。
- 为人物包校验、人物会话接口、范围隔离、前端导航和关键浏览器流程增加测试。

## Capabilities

### New Capabilities

- `celebrity-dialogue`: 定义人物目录、人物包加载与校验、人物会话初始化、历史人物对话体验、来源披露和安全边界。

### Modified Capabilities

无。当前仓库尚无已发布的 OpenSpec 能力规格；现有术数聊天行为保持不变。

## Impact

- 前端：`AppShell` 产品导航、人物大厅、人物对话工作区、会话类型与 API 客户端。
- 后端：人物包注册表、人物提示词编译器、人物会话初始化接口、按会话类型选择范围策略。
- 数据与内容：新增内置人物包目录及王阳明资料、来源和 MIT 许可证归属。
- 现有系统：复用 `ChatOrchestrator`、SSE 流式输出、额度和会话存储；不新增模型服务。
- 部署：人物包随应用版本发布，不提供运行时任意远程 Skill 安装。
