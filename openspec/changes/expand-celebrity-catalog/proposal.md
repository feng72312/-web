## Why

当前“名人对话”只有王阳明一位人物，无法形成真正可探索的人物馆。`nuwa-skills/awesome-nuwa` 已整理出一份声称包含 159 位人物、18 个领域的清单，适合作为目录来源，但其中同时存在已故历史人物、在世公众人物、第三方仓库以及分类计数漂移，必须经过授权、身份和来源审核后才能安全接入。

## What Changes

- 将 awesome-nuwa 当前目录中的全部人物条目纳入本地人物目录快照，并保留上游仓库、提交版本、作者和许可证信息。
- 建立 18 个领域分类、主题标签、中文搜索、筛选、分组统计和人物推荐入口；实际条目数以导入审计结果为准，不盲信 README 声明计数。
- 为人物增加 `historical`、`living`、`unknown` 身份状态以及 `ready`、`review_required`、`unavailable` 可用状态。
- 已故人物继续使用明确披露的史料型思想模拟；在世人物只允许“公开思想框架分析”，禁止冒充本人、第一人称亲历、实时立场和背书。
- 只有许可证、上游来源和人物边界全部通过校验的人物才能创建会话；其余人物仍可在目录中展示审核状态，但不可发起对话。
- 新增可重复运行的批量导入与审计流程，从上游仓库提取 Skill、研究资料和许可证，并生成受控的本地人物包，而不是运行上游代码。
- 扩展人物馆为可承载百余人物的分类浏览界面，同时保持现有王阳明会话和历史记录兼容。

## Capabilities

### New Capabilities

- `celebrity-catalog`: 全量人物目录快照、分类检索、上游授权审计、人物可用状态以及历史人物/在世人物的差异化对话边界。

### Modified Capabilities

无。该变更建立在已完成但尚未归档的 `add-celebrity-dialogue` 变更之上，不修改当前 `openspec/specs/` 下的既有主规格。

## Impact

- 后端人物类型、注册表、公开 API、bootstrap 安全合同和测试。
- 新增上游目录导入/审计脚本及生成的本地人物包或目录快照。
- 前端人物馆、分类导航、搜索筛选、状态提示、人物卡和详情页。
- 本地部署制品体积、构建时间和人物数据维护流程。
- 外部来源：[`nuwa-skills/awesome-nuwa`](https://github.com/nuwa-skills/awesome-nuwa) 及其链接的 `nuwa-skills/*`、`alchaincyf/*` 人物仓库。
